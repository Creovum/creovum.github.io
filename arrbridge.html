The idea

Make the pieces work together.

ArrBridge is a personal server-side tool built to improve matching between release names and Sonarr series metadata. It helps with cases where Swedish release titles differ from the English names used in TVDB and Sonarr.

It is a privately developed project, not a public release. The diagram shows the related applications in the homelab workflow; it is illustrative rather than a guarantee of every integration path.
